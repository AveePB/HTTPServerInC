# HTTPServerInC
A lightweight HTTP server written in C, built to explore low-level network programming, POSIX sockets and HTTP communication on Linux. It was bulit for educational purposes.

## Overview
**HTTPServerInC** is a project focused on understanding how an HTTP server works internally, from accepting client connections to processing HTTP requests and returning responses. Instead of relying on high-level web framework, this project uses C and system-level networking APIs to explore the fundamentals of client-server communication and HTTP protocol handling.

## Getting Started

### Prerequisites
Make sure you have the following installed:
- Linux or compatible POSIX environment;
- GCC or Clang;
- CMake;
- GNU Make or another supported build tool;

### 1. Clone the repository
```
git clone https://github.com/AveePB/HTTPServerInC.git
cd HTTPServerInC
```
### 2. Build the project
Configure the project using CMake:
```
cmake -S . -B build
```
Compile the source code:
```
cmake --build build
```
### 3. Run the server
Launch the executable generated by the build process. The file is in the build directory.
```
cd build
./HTTPServer
```
## Running Tests
The repository includes a test script located at `assets/run_40_tests.sh`.

### 1. Grant execution permissions
From the repository root, run:
```
chmod +x assets/run_40_tests.sh
```
### 2. Run the test suite
Execute the script and save both standard output and error output to a results file:
```
cd assets
./run_40_tests.sh > test_results.txt
```
### 3. View the test results
After the tests finish, inspect the output:
```
cat test_results.txt
```
